# 訂製計算機程式服務 — 商業模型 v1

## 核心賣點

不要只賣「一條計算機 Program」。真正可收費的是：

**Past Paper / 題庫分析 → 找出可程式化題族 → 設計演算法 → 指定機型原生程式 → 驗算與壓縮 → 使用教學**。

這比一般「幫我寫個程式」更專業，亦能把客單價由單一程式提升到整份 Paper / 整門 Course。

## 三層產品

### 1) Single Program
適合已知道自己要甚麼的客戶。用低價入門，目標是快速成交與累積案例。

### 2) Paper Analysis Pack
主力產品。客人提供 Past Paper，你替他判斷哪些題型值得做，再把最高 ROI 的幾類做成 Program。這最能體現 Math Expert 的優勢。

### 3) Course Suite
高客單。按一門大學科或一整套考試建立 Program 組合、統一操作邏輯、教學文件和版本更新。

## 建議銷售漏斗

1. 免費初評：客戶提交 1–3 份 sample / paper link。
2. 回覆「可程式化地圖」：A 類非常適合、B 類可做但收益低、C 類不建議。
3. 給固定 scope 報價，而不是按時薪。
4. 收訂金後開發。
5. 先示範 1–2 題輸入輸出；確認 workflow。
6. 完成交付、收尾款。
7. Upsell：再加 paper / 題型 / 第二個 calculator model / 期末更新版。

## 報價邏輯

價格不應以「代碼幾 bytes」計，而應考慮：

- 要分析多少題目
- 是否能形成共用題族
- 演算法難度
- 分支／退化情況
- 是否要數值方法
- 是否要跨模式或跨機型
- 是否要極限壓縮
- 驗證案例數量
- 文件與教學要求
- deadline / rush

## 差異化文案

- 「不是把答案硬塞入計算機，而是把題型變成可重用演算法。」
- 「先判斷值不值得 Program，再收費。」
- 「交付的不只是 code，而是一套你知道何時用、怎樣輸入、如何讀結果的工具。」
- 「可靠版先驗算，再做安全壓縮。」

## 操作 SOP

每單至少保存：

1. 客戶原始資料
2. 題型分類表
3. Program scope
4. 清晰版演算法
5. 壓縮成品
6. 測試案例與答案來源
7. 版本號
8. 客戶機型／模式
9. 已知限制
10. 最終交付 PDF / README

## 風險控制

- 不承諾所有題都可以 Program。
- 不把主機模擬寫成「已實機測試」。
- 不承諾未量測的 bytes。
- 不承諾在任何考試必然准用。
- 不提供隱藏資料、繞過監考或違反考試規則的做法。
- 客戶提供有版權限制的 Past Paper 時，只用於分析／客戶服務，不將整份試卷公開作網站素材。

## 可擴展收入

- Exam-specific Program Pack
- 每學期版本更新
- 同一課程 group buy
- Tutor / 補習社 B2B 授權
- 不同 calculator model porting
- Program review / compression service
- 付費 video onboarding
- 私人客戶 portal + 版本更新

## 最值得先驗證的商業假設

1. 客人願意為「分析 + Program + 教學」付多少，而不是只為 code 付多少。
2. 哪一類大學課最常出現固定可參數化題型。
3. 客戶獲取渠道：同學群、course forum、tutor、學生會／學科群組，哪個轉換最高。
4. Single Program 是否能有效帶到 Paper Pack。
5. 交付後最常見 support 問題，用它反推 FAQ 和教學格式。
